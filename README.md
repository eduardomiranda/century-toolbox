# 📄 PDF Watermark Encryptor

Aplicação em **Streamlit** que permite adicionar **marcas d’água personalizadas** em arquivos PDF e proteger os documentos com senha.  
Ideal para uso em documentos confidenciais que precisam de identificação visual e segurança extra.

---

## ✨ Funcionalidades
- Upload de arquivos PDF diretamente pelo navegador.
- Criação automática de marca d’água com **dois textos customizáveis**.
- Aplicação da marca d’água em todas as páginas do PDF.
- Criptografia do documento com **senha definida pelo usuário**.
- Download do PDF final processado.

---

## 🛠️ Tecnologias utilizadas
- [Python 3.9+](https://www.python.org/)
- [Streamlit](https://streamlit.io/) → Interface web
- [ReportLab](https://pypi.org/project/reportlab/) → Geração da marca d’água
- [PyPDF2](https://pypi.org/project/PyPDF2/) → Manipulação e criptografia de PDFs
