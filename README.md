# Century Toolbox

Ferramentas Streamlit para PDFs, reunidas num app multipágina.

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 📎 Merge de PDFs

1. Envie os PDFs.
2. Confira a capa de cada PDF e use ◀ ▶ para mudar a sequência.
3. Clique em **Combinar PDFs** e baixe o resultado.

## 🔒 Marca d'água e senha

1. Envie um PDF.
2. Defina os dois textos da marca d'água e a senha.
3. Clique em **Gerar PDF final** e baixe o documento com marca d'água em todas as páginas e protegido por senha.
